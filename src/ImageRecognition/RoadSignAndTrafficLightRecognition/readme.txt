Most scripts work to standardize data from multiple different datasets to train an image recognition Yolov8 model for the project to recognize traffic signs and traffic lights on the road. The datasets are downloaded and their .zip files can be found in the "Data/raw" folder. After they have been unzipped, the scripts integrate the images with the rest of the training data in "Data/train + val + test" and the labels as well which often need to be converted into Yolov8 text document format labels and certain classes need to be adjusted as well. After integration to conserve space the dataset contents are deleted only the zip files are kept. Those too will most likely be removed later and just links to the original dataset sources will be left.
